# CHANGES

## v1.0.0

- **Mermaid ↔ TGF conversion (both ways)** — Convert Mermaid flowcharts to TGF and TGF to Mermaid.
- **Static web UI** — Copy/paste Mermaid or TGF, convert in the browser, download result. Run `mermaid2tgf serve` to use the embedded site.
- **CLI** — Convert from stdin or a file: `mermaid2tgf [file]` or pipe input; no args reads stdin.
